Portfolio Tracker

Connect Firebase to sync your portfolio across all devices in real time. You only do this once per device.

1
Go to console.firebase.google.com → Create a project (skip Analytics).
2
Build → Realtime Database → Create database. Choose any region, pick Start in test mode.
3
Click the ⚙ gear → Project Settings → scroll to Your apps → click </> Web → register app → copy the firebaseConfig.
4
Paste the full config JSON below and click Connect.
💡 Config is saved in this browser — you won't need to paste it again on this device.
